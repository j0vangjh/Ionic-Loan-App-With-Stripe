"# Ionic-Loan-App-With-Stripe" 

1. npm install @stripe/stripe-js in skippyQ and npm install --save stripe

2. Backend packages to install npm install express body-parser stripe cors dotenv

3. npm init -y

4. You need to change the server.js code in backend and front end app.component.ts to your own firebase credentials
   
5. Import your stripe secret key in server.js and thankyoupage.ts

6. Cd backend and run server.js, node server.js, it will run on local host 4242

7. Split your terminal and run ionic serve in the skippyQ not in backend

8. Run the code if it cant work go to the console you will see this error to create index for both loans and transactions

9. Click on the link and create the index in firebase

10. After the index is created, the code should work as normally with the stripe payment, you need to change the date in your firebase to a date before today for the payFine() button to show up
